- Severity: medium
- Category: test-gap
- Summary: The new path-setup validation scenarios cover current-repo, custom-path, and skip-for-now when Git is detected, but none exercise the branch where Git is not present and "Use current Git repo" must be omitted from the options.
- Evidence: `scripts/validate-vazir-vcs-mirror-settings.mts` calls `initGitRepo` in all three new scenarios (`runCurrentRepoPathScenario`, `runCustomPathScenario`, `runSkipPathScenario`), so `resolveGitTopLevel` always returns a value and the conditional `if (gitTopLevel)` in `promptMirrorPathSetup` is always true. The `else` branch — where only "Enter custom path" and "Skip for now" are offered — has no regression coverage.
- Recommendation: Add a scenario that enables mirror mode in a project with no Git metadata and asserts that "Use current Git repo" is not offered and that choosing "Skip for now" still warns correctly.
- Rule candidate: When a UI flow has conditional option branches based on environment state, add at least one regression test for each branch (present vs. absent).
