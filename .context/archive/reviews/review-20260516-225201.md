## Findings

### Finding 1
- **Severity:** medium  
- **Category:** test-gap  
- **Summary:** No end-to-end validation ensures the `/consolidate` handler calls `updateRuleConfidence()` and `organizeLearnedRules()`. The existing tests validate the helpers in isolation; a future refactor could drop the wiring silently.  
- **Evidence:**
  - `.pi/extensions/vazir-context/index.ts` line ~2775: handler calls `updateRuleConfidence(ctx.cwd)` and `organizeLearnedRules(ctx.cwd)`.
  - `scripts/validate-vazir-confidence-and-subsections.mts` tests `updateRuleConfidence` and `organizeLearnedRules` against synthetic temp directories.
  - `scripts/validate-vazir-fallow-signal-sources.mts` tests instruction text and downstream confidence updates against synthetic temp directories.
  - Neither script loads the extension module and asserts that the `/consolidate` handler invokes both functions in the correct order.
  - The previous regression (story-014 VCS closeout refactor) removed exactly this wiring without breaking any tests.
- **Recommendation:** Add an end-to-end validation test (or extend an existing one) that loads the extension module, invokes the `/consolidate` handler against a synthetic project, and asserts that `system.md` contains confidence annotations and failure/success subsections afterward.
- **Rule candidate:** When restoring handler wiring for a previously regressed feature, add an end-to-end test that asserts the call sequence so future refactors cannot silently drop it again.

### Finding 2
- **Severity:** low  
- **Category:** test-gap  
- **Summary:** The restored `buildConsolidationInstruction` text is only partially validated. Existing tests assert `[fallow]` and `/fix` mentions but do not cover the story-007 additions (story completion summaries, `decisions.md`, subsection organization instructions, confidence preservation).  
- **Evidence:**

  - It does not assert `"story completion summaries"`, `"decisions.md"`, `"From failures"`, `"From successes"`, or `"confidence:"` in the instruction text.
  - The instruction currently has 12 task lines; the old regressed version had 8. The delta is large but unvalidated.
- **Recommendation:** Extend `validate-vazir-fallow-signal-sources.mts` (or add a dedicated test) to assert that the consolidation instruction mentions story completion summaries, decisions.md, subsection organization, and confidence preservation.
- **Rule candidate:** When expanding prompt instructions, extend the corresponding validation script to assert new instruction clauses so drift is caught automatically.
