## Findings
### Finding 1
- Severity: medium
- Category: regression
- Summary: `commitStoryCloseChanges()` can take the JJ path even when the saved active mode is Git, so “Close story and commit all” may stop producing a Git commit in colocated Git/JJ repos.
- Evidence: `.pi/extensions/vazir-context/helpers.ts:326-339` reads `active_vcs_mode`, but after the Fossil branch it immediately checks `if (detectJJ(cwd))` before `if (detectGitRepo(cwd))`. In a repo with `active_vcs_mode: "git"` and JJ installed, closeout will run `jj describe -m ...` and report `Recorded JJ change...` instead of creating the expected Git commit.
- Recommendation: Dispatch closeout commits by the persisted active mode first (`git` vs `fossil` vs `none`), and only use fallback probing when no active mode is set. Add a regression test for a colocated Git/JJ repo with `active_vcs_mode: "git"`.
- Rule candidate: When a workflow persists an active backend/mode choice, write follow-up actions against that persisted mode instead of re-probing a different backend first.

### Finding 2
- Severity: medium
- Category: test-gap
- Summary: The new `.context` closeout policy is not covered for its main guarded branches: dirty `.context`, Fossil mode, or JJ mode.
- Evidence: `scripts/validate-vazir-complete-story.mts:32-39` only provisions a plain Git project for commit testing, and `:388-412` only asserts `Committed with Git: complete story-001`. There are no complete-story validations for the `.context` enforcement prompt (`"Commit .context changes and close story"`), no Fossil closeout assertion (`"Committed with Fossil"`), and no JJ closeout assertion (`"Recorded JJ change"`).
- Recommendation: Add completion-review validations for (1) pending `.context` changes with the explicit commit/decline prompt, (2) Fossil active mode, and (3) colocated Git/JJ with both Git-active and JJ-active settings.
- Rule candidate: Add one validation per supported VCS mode and per protected decision branch whenever closeout behavior depends on persisted VCS mode or commit-policy prompts.
