## Findings
### Finding 1
- Severity: medium
- Category: robustness
- Summary: VCS inspection failures are treated as a clean `.context` state.
- Evidence: `listUntrackedContextFiles()` catches Fossil/Git command failures and returns `[]`; existing persistence helpers similarly swallow `fossil extras` failures. A missing, invalid, or unavailable VCS executable can therefore suppress the warning and make the workspace appear safe when untracked `.context` files may exist.
- Recommendation: Return an explicit inspection-error result or surface a warning when the active VCS inspection fails. Do not represent an inspection failure as an empty file list.
- Rule candidate: Do not silently swallow exceptions from structural persistence operations; surface a warning when tracking or recovery state cannot be verified.
